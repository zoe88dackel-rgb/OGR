什么样的卖家，
可以参与？

新老卖家的主要区别在是否已有 Ozon 账户；项目的商品、主体、备货和预审条件需要共同满足。

共同条件，先看这四项。

01主体现有项目资料面向中国大陆或香港有限公司；其他主体类型待确认。
02收款准备与企业主体匹配的收款资料，具体账户要求待确认。
03货源与资金具备真实货源和批量备货能力。原稿提及 8 万元备货门槛，计价口径待确认。
04商品审核需要按 SKU（单个商品规格）提交审核；品牌授权、认证及标签视商品而定。

供应链稳定、报价有竞争力、品牌资源和跨境经验可作为招商优先考虑因素，不应直接混写成所有卖家的强制准入项。

新卖家和老卖家，区别在哪里？

新卖家｜还没有 Ozon 店铺

核对注册主体和项目申请要求 → 完成注册 → 取得 Seller ID（店铺编号）→ 申请新模式权限。

老卖家｜已经拥有 Ozon 店铺

准备现有 Seller ID → 与原招商或项目经理确认新模式权限 → 按新模式要求提交商品预审。

商品合规不能靠简单类目判断

EAC 是欧亚经济联盟的产品合格评定相关标志；HS Code 是商品海关编码。是否需要具体认证、是否允许进口与销售，必须结合 SKU 属性、品牌、用途和法规审核。
