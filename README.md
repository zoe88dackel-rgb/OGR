# Ozon 新模式讲解（OGR · 讲解结构实验分支）

本分支以外部中国卖家（尤其有供应链的卖家）和 GUOO 业务同事为主要读者，目标是在约 10 分钟内建立对新项目的完整初步认知。

## 页面结构

- 首页 `index.html`：一句话定位 + 可点击的业务全流程 + 六问总览 + 入驻/成本/参与要点
- `model.html`：模式是什么
- `compare.html`：为什么值得了解、与现有模式的差别
- `shipping.html`：货物流和资金流（不含虚构逐节点日期）
- `finance.html`：费用结构和待确认口径
- `categories.html`：共同条件及新老卖家区别
- `start.html`：从咨询、预审到发运
- `resources.html`：原有资料与工具集中查阅
- `verification.html`：需与项目经理核实的关键政策
- `guide.css`：保留原设计语言的新增响应式讲解样式

## 核心原则

- 国内集货中转和俄罗斯本土仓是不同的业务环节。GUOO 可提供境内集货转运服务，不写作 Ozon 指定仓或唯一交接点。
- 不把原汇编中未核对的佣金、运输、VAT、时效、结算等写成已生效条款。
- 删除旧“货物旅程”中无出处的分节点天数；在新版货物流页只介绍流程顺序。
- 旧费率表、EAC 资料、回款说明、利润计算器暂作为参考资料保留， **不等于已重新核实** 。
- 正式对外发布前需要复核原始协议、费用表、适用地区、交接点、税务和商品准入文件。

## 本地预览

纯静态 HTML，无需构建。可以在仓库目录启动简单静态服务器（如 `python -m http.server 8000`）访问 `index.html`。
GitHub Pages 通常只发布已配置的默认分支；此实验分支需通过 PR 合并或单独部署后才有公开预览网址。
