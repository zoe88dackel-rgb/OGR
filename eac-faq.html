一、基础概念（1–20）

什么是 EAC 认证？

EAC 是欧亚经济联盟统一强制性合格评估制度，证明产品满足 EAEU 技术法规 TR CU/TR EAEU，拿到 EAC 文件 + EAC 标识，可在五国自由流通销售，类似欧盟 CE、国内 3C。

EAC 和 CU-TR 是同一个东西吗？

是的，早期叫 CU-TR（海关联盟技术法规认证），现在统一俗称 EAC 认证。

EAC 证书在哪些国家有效？

俄罗斯、白俄罗斯、哈萨克斯坦、亚美尼亚、吉尔吉斯斯坦，一证五国通用。

EAC 是自愿认证还是强制认证？

纳入 EAEU 技术法规目录的产品强制；不在目录内产品不需要 EAC，可做自愿 GOST。

GOST 和 EAC 有什么区别？

GOST 是俄罗斯旧国标自愿认证；EAC 是联盟统一强制体系。很多产品已经取消旧 GOST 强制，改为 EAC。

是不是所有出口俄罗斯的货都要 EAC？

不是，先查 HS 编码对应的技术法规，不在 TR CU 目录内，不需要 EAC。

TR CU 是什么？

TR CU = Технический регламент Таможенного союза，海关联盟技术法规，每一条法规对应一类产品安全要求（如低压、机械、儿童用品）。

EAC 和 CE 可以互相替代吗？

不可以。CE 是欧盟，EAC 是欧亚联盟；有 CE 证书不能直接在俄清关上架，仅可作为辅助测试参考文件。

EAC 分为哪两大类？

EAC CoC（合格证书）、EAC DoC（符合性声明），两者法律效力不一样、发证规则不一样中国国际贸...。

EAC CoC 是什么？

合格证书，高风险产品，由 EAEU 认可发证机构签发，需要实验室测试 + 工厂审核 + 年度监督审核。

EAC DoC 是什么？

符合性声明，中低风险产品，申请人（联盟境内代表）自行声明合规，备案在 Arshin 系统，一般不需要审厂，但必须留存全套技术文件 + 测试报告，申请人承担全责。

Arshin 是什么系统？

Arshin（ФГИС «Аршин»）是欧亚联盟统一证书备案数据库，所有 EAC CoC/DoC 都要在此注册，海关、平台、监管都在这个库核验证书真伪。

什么是欧亚授权代表（EAEU Authorized Representative）？

EAC DoC/CoC 要求申请人必须是欧亚联盟境内合法主体（俄 / 哈 / 白俄等公司），中国工厂不能直接作为申请人，这个主体就是授权代表，承担法律连带责任中国国际贸...。

授权代表可以同时代理多个工厂品牌吗？

可以，但要注意风控：同一个代表名下大量不同卖家、不同品牌集中出证，容易被 Arshin 标记高风险。

单批次 EAC 证书是什么？

CoC 的一种方案，仅对应某一批次货物，一批一证，不能重复使用，无年审，适合一次性大货项目，不适合电商长期铺货中国国际贸...。

系列 EAC 证书是什么？

覆盖一个产品系列多个型号，有效期 1/3/5 年，可以多次出货；CoC 长周期版本每年需要监督审核。

EAC 证书有效期有哪几种？

CoC：单批次、1 年、3 年、5 年；DoC：最长 5 年，无年审要求，到期必须重办，不能续期。

EAC SGR 是什么？

和 EAC 是一回事吗？ SGR 是国家注册证，针对化妆品、食品、消毒剂等卫生类产品，属于另外一套注册体系，不属于 EAC CoC/DoC。很多化妆品同时需要 SGR+EAC。

Chestny Znak（诚实标记）和 EAC 关系？

EAC 是准入合规；Chestny Znak 是俄罗斯商品溯源二维码（鞋服、烟草、水等品类强制打码），两套体系，互不替代，部分品类两者都要。

出口哈萨克斯坦，有俄罗斯出具的 EAC 证书能用吗？

可以，联盟内任意成员国认可机构签发的 EAC，五国通用。

二、证书类型、适用产品（21–40）

哪些产品一般做 EAC CoC（合格证书）？

玩具、燃气设备、防爆电气、压力容器、电梯、个人防护 PPE、低压成套、医疗设备、儿童贴身用品等高危品类。

哪些产品一般做 EAC DoC（符合性声明）？

普通小家电、成人外套、箱包、家具、普通灯具、塑料配件、包装、纺织品（非贴身）、普通五金等中低风险品。

低压产品对应的 TR 法规编号？

TR CU 004/2011 低压设备安全。

机械设备对应的 TR 法规编号？

TR CU 010/2011 机械设备安全。

儿童用品对应的 TR 法规编号？

TR CU 007/2011 儿童及青少年产品安全。

纺织品鞋服对应的 TR 法规编号？

TR CU 017/2011 轻工产品安全；贴身内衣一般 CoC，外套 DoC。

电磁兼容 EMC 对应的 TR 法规编号？

TR CU 020/2011 电磁兼容性。

一个产品是否可能同时满足多条 TR 法规？

是的。例如一台小家电，同时满足 TR CU 004（低压）+ TR CU 020（EMC），证书上要列明全部适用法规。

同一个证书可以包含多个型号吗？

可以，系列证书允许同结构、同材质、同原理的多个型号列入证书附件；差异大的型号不能混在同一份证书。

品牌不一样，可以共用同一份 EAC 证书吗？

不可以，证书绑定品牌 + 制造商；换品牌必须单独出证。

制造商工厂换地址，原有 EAC 证书还有效吗？

CoC 证书：工厂地址变更属于重大变更，证书失效，需要重新审核；DoC：也需要更新备案文件，否则平台 / 海关判定无效。

证书上的型号和我上架销售型号不一致，可以吗？

不可以，平台稽查、海关查验会直接判定证书不匹配，扣货下架。

DoC 证书是否不需要测试报告？

法规要求必须有支撑测试报告，只是不需要发证机构现场审厂；报告要保存在技术文件包，监管随时调取。

CoC 证书年审不做会怎么样？

证书直接在 Arshin 系统注销失效，货物无法清关、平台直接下架封店，已经在仓货物会被处罚。

单批次 CoC 证书可以重复多次清关吗？

不行，仅限申报的这一批货物，数量、批次锁定。

EAC 证书可以转让给别的卖家 / 工厂吗？

不可以，证书绑定申请人、制造商、品牌，不可转让。

无品牌白牌产品能不能办理 EAC？

可以，证书品牌栏标注 “无品牌 / No brand”，但要和平台上架信息保持一致。

配件、散件需要 EAC 吗？

看 HS 编码和技术法规：如果是独立投放市场销售的配件，纳入目录就要 EAC；单纯整机配套散件、不单独流通，一般不需要。

电池单独出口俄罗斯要不要 EAC？

锂电池属于 TR CU 004/2011、TR CU 020/2011 范围，需要 EAC。

食品需要 EAC 吗？

食品适用 TR CU 021/2011 食品安全，同时需要食品注册，不属于普通工业品 EAC。

三、办理资料、流程、周期费用（41–55）

办理 EAC 一般需要提供哪些基础资料？

申请表、产品 HS 编码、产品图片、铭牌、俄文说明书、技术规格书、BOM 清单、样机、ISO9001（可选加分）、过往测试报告、制造商信息、品牌资料。

DoC 一定要俄文技术文件吗？

是的，技术档案（Технический файл）必须俄语版本，监管核查只认俄文。

国内实验室出的测试报告可以用来做 EAC DoC 吗？

可以，前提是测试标准对应 TR CU 要求，报告信息完整；发证机构有权评估报告是否采信。CoC 高风险产品大多要求联盟认可实验室测试。

EAC 办理完整流程？

①提供 HS 判定适用 TR、确定 CoC/DoC 方案；②签约，欧亚代表就位；③资料 + 样品测试；④文件审核 / CoC 安排工厂审核；⑤草稿核对；⑥Arshin 系统注册；⑦下发带注册号证书中国国际贸...。

DoC 办理周期大概多久？

资料齐全，1–3 周。

CoC（5 年系列）办理周期大概多久？

样品测试 + 工厂审核，一般 1.5–4 个月，视产品测试复杂度。

EAC 证书办理价格大概区间？

DoC 基础款：4k–8k；普通 CoC：1.5w–5w；防爆、承压、医疗等高风险价格更高；单批次价格偏低，但是只能一次使用。

证书注册完成后，会给什么文件？

证书原件扫描件、Arshin 系统注册截图、证书注册号、全套俄文技术档案包。

证书上的注册号格式是什么样？

DoC 常见：RU D-RU.XX.XX.XXXXXX；CoC：RU C-RU.XX.XX.XXXXXX，不同签发国前缀有区别。

我可以自己直接在 Arshin 注册 EAC 吗？

个人 / 中国工厂不行；必须由 EAEU 境内授权代表 + 持证认证机构操作注册。

工厂审核审什么内容？

CoC 审厂：生产质控、来料检验、成品测试、文件体系、不合格品管控、记录留存，对标 TR 法规要求。

异地工厂，同一个证书可以覆盖多个生产地址吗？

CoC 原则上每个生产场地都要纳入审核范围，新增工厂要报备发证机构变更。

证书草稿确认后还能修改型号、参数吗？

小修改可以走变更；重大修改（法规、型号范围、制造商）建议重新出证。

证书到期前多久启动重办合适？

建议提前 3 个月启动，避免证书断档、仓内商品被平台下架。

证书到期后，老证书还有缓冲期吗？

没有，到期当天自动失效，不能继续销售和清关。

四、电商平台上架（Yandex/Ozon/WB）（56–70）

Yandex Market 上架为什么要 EAC？

平台合规规则：纳入 TR CU 强制目录商品，上架审核、抽检、风控核验都要求上传有效的 Arshin 可查 EAC 文件；无证书直接驳回上架、冻结商品、店铺处罚。

平台核验 EAC 证书是查哪里？

对接 Arshin 数据库，输入证书注册号核验真伪、有效期、产品型号匹配度。

平台上传 EAC，只传中文版本可以吗？

不行，平台要求证书原件（俄文制式），中文翻译件仅作辅助。

同一份 EAC 证书可以绑定多个 SKU 吗？

只要 SKU 型号、参数、品牌都在证书附件清单内，就可以绑定；超出型号范围不行。

卖家提供 EAC 证书，平台风控怎么核查资料真实性？

①Arshin 联网核验状态；②核对证书申请人（欧亚代表）信息；③核对型号、HS、TR 法规；④联系欧亚授权代表核实是否真实授权；⑤抽查技术文件、测试报告；这一条和你前面 Yandex 卖家审核风控场景匹配。

为什么很多卖家提供的 EAC 在 Arshin 查不到？

①假证；②草稿，还没有完成注册；③注册号录入错误；④证书已经被注销撤销。

平台查到 EAC 假证处罚是什么？

商品下架、扣罚保证金、限制上新、封店；严重会移交俄监管部门。

DoC 和 CoC 在平台权重、审核严格度上有差别吗？

CoC 审核信任度更高；DoC 更容易触发二次抽查，平台会要求卖家补充全套技术档案、测试报告。

铺货卖家批量做 DoC 证书有什么风险？

同一个欧亚代表短时间大量出证、大量陌生店铺共用同一个代表，属于风控高危特征，容易批量被平台核查、证书集中锁证。

店铺转让，EAC 证书跟着店铺一起生效吗？

证书绑定制造商 / 品牌，不绑定店铺；新店上架依然可以用，前提店铺主体和证书授权链路清晰。

样品、测款链接上架俄罗斯，要不要 EAC？

只要投放联盟市场销售，样品售卖链接同样需要合规 EAC；纯免费样品不流通售卖另说。

海外仓备货，到货之后才补 EAC 可以吗？

风险极高；入库、平台巡检随时核查，无证书商品会被锁定、退回、销毁。

不同平台（Ozon、Yandex、WB）EAC 证书互通吗？

证书本身是官方文件，平台之间认可同一份有效 EAC，只是每家平台上传字段、审核规则略有差异。

平台要求 EAC 证书上必须显示卖家店铺名称吗？

不需要；证书主体是制造商 + 欧亚授权代表，店铺只是销售方。

灰色 EAC（套证、PS 证书）是什么？

套用别人证书编号、P 图修改型号，属于虚假合规文件，现在 Arshin 实时联网校验，很容易被 AI 风控识别，也是当前俄电商重点打击类型。

五、清关、查验、海关风险（71–80）

俄罗斯清关，什么时候海关会查验 EAC？

申报时系统校验、随机布控查验、重点品类专项稽查；低压、玩具、儿童用品是高频查验品类。

没有 EAC 强行清关后果？

扣货、罚款（货值 30%–100%）、退回、销毁，进口商（欧亚代表）承担主要法律责任。

清关资料上型号、品牌和 EAC 不一致会怎么样？

直接判定不合规，扣货。

DoC 清关效力和 CoC 一样吗？

法律上同等有效，只是查验时海关更容易要求 DoC 提供全套支撑测试报告备查。

EAC 标识一定要印刷在产品本体吗？

优先打在产品铭牌；如果空间不足，可以打在外包装或随附文件上，标识尺寸≥5mm，清晰耐久，和底色有对比色Евраз...。

已经贴 EAC 标识，但是证书过期了，合法吗？

不合法，标识只有在证书有效期内才允许使用。

一批货同时销往俄罗斯和哈萨克斯坦，只需要一份 EAC？

是的，一份 EAC，任意口岸清关后联盟内自由流转。

海关查验 Arshin 显示证书 “приостановлено（暂停）” 是什么意思？

证书被监管临时冻结，暂停效力，货物禁止放行，需要联系发证机构核查原因、申诉解除。

证书注销（аннулирован）和暂停有什么区别？

注销：永久失效，无法恢复；暂停：临时冻结，可申诉恢复。

用中国进口商作为清关主体，可以吗？

清关必须有欧亚联盟境内进口主体，也就是 EAC 上的申请人 / 授权代表。

六、技术档案、档案留存责任（81–88）

EAC 技术档案（Технический файл）包含哪些？

产品描述、图纸、BOM、测试报告、俄文说明书、铭牌样稿、风险分析、证书副本、合规声明、工厂质控记录等。

技术档案保存多久？

法规要求：产品停止生产后至少保存 10 年，由欧亚授权代表负责保管，监管随时可以调取。

DoC 证书发证机构会保管技术文件吗？

多数机构只留存证书备案，完整技术档案保管责任属于申请人（欧亚代表）。

如果欧亚代表失联，技术档案拿不出来怎么办？

平台、海关核查时无法提供档案，直接判定证书失效，这是跨境卖家非常高频踩坑点。

换了新的欧亚代表，老 DoC 证书还能用吗？

证书申请人是旧代表，依然有效；但是后续补文件、应对稽查只能找旧代表；建议到期后用新代表重新出证。

测试报告过期了，DoC 证书还在有效期，合规吗？

证书本身有效期看证书；但支撑测试报告如果失效，监管稽查可以判定支撑材料不足，要求重新测试。

技术档案只给中文版本行不行？

不行，监管问询、海关稽查、平台复核，有权要求提供俄语全套文件。

产品改版改内部结构，外观不变，原有 EAC 是否有效？

内部结构变更，若影响 TR 法规安全指标，证书失效，需要重新评估测试。

七、证书核验、真假查询（89–94）

EAC 证书官方查询网址是什么？

Arshin（ФГИС «Аршин»），欧亚联盟统一公共数据库。

查询证书需要什么信息？

证书注册号；优先用注册号查询，不要只靠产品名称搜索。

Arshin 查到证书信息，就代表一定可以上架吗？

不是，还要核对：型号、品牌、制造商、适用 TR 法规、有效期，是否和你售卖商品匹配。

证书在 Arshin 能查到，但平台判定无效是什么原因？

型号不匹配、法规选错、证书暂停 / 限制使用、欧亚代表资质异常、证书备注限定使用条件。

假 EAC 证书常见特征？

无 Arshin 注册号、官网查不到、PS 修改日期型号、发证机构不在联盟认可名录、格式版式不符合 EEC 第 154 号决议模板。

收到证书后，卖家第一步核验动作是什么？

立刻去 Arshin 输入注册号核验状态，截图留存核验记录。

八、高频误区、风控避坑（95–100）

误区：有 CE 报告就不用做 EAC 测试

错，标准体系不同，CE 报告仅能作为参考，不能直接替代 EAC 合规评估。

误区：DoC 就是花钱买一张纸，不用管测试报告

错，DoC 是自我声明负责制，法律责任最重，一旦出事欧亚代表和卖家连带承担罚款召回。

误区：5 年 CoC 证书，拿到之后就不用管了

错，CoC 每年强制监督审核，不年审直接注销。

误区：EAC 证书可以通用所有同类产品，只改 SKU 名称

错，证书型号清单是刚性范围，超出即套证违规。

误区：不在 EAC 强制目录的产品，也需要办一张 EAC 备用

错，无对应 TR 法规的产品，不需要 EAC，自愿认证非强制。

误区：欧亚授权代表只是一个挂名主体，不会承担责任

错，授权代表是 EAEU 法律上的责任人，海关、市场监管、平台追责第一顺位就是该主体；大量卖家踩坑：代理失联、被罚款、证书被批量锁证。
